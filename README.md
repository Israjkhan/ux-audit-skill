# UX Audit — AI UX Reviewer

An AI-powered UX audit skill for Figma that reviews screens and user flows for usability, accessibility, information architecture, interaction, UX writing, responsive risks, conversion friction, and missing states.

## What it does

UX Audit evaluates selected Figma screens and flows and produces:

- UX score
- Prioritized UX issues
- Severity levels
- Evidence-based findings
- Actionable recommendations
- Missing-state analysis
- Quick wins
- Recommended fix order

## Audit modes

- Full UX audit
- Quick audit
- Accessibility audit
- Conversion audit
- Flow audit
- SaaS audit

## Installation

Add `SKILL.md` to your agent's skills directory and use the skill with your Figma-compatible AI agent.
